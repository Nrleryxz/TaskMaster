# TaskMaster - Yapılacaklar Listesi
a
TaskMaster, modern, basit ve kullanışlı bir yapılacaklar listesi uygulamasıdır.

## Özellikler
- Görev ekleme, tamamlama (üstü çizilir) ve silme
- Karanlık/Açık mod geçişi
- Responsive tasarım (mobil uyumlu)
- LocalStorage ile görevler tarayıcıda kaydedilir

## Kullanım

1. Görev eklemek için kutucuğa yazın ve 'Ekle' butonuna basın.
2. Görevi tamamlamak için üzerine tıklayın.
3. Görevi silmek için sağdaki '✕' butonuna basın.
4. Karanlık mod açmak/kapatmak için üstteki butona basın.

## Kurulum

1. Depoyu klonlayın veya ZIP dosyasını indirin.
2. `index.html` dosyasını bir tarayıcıda açın.
